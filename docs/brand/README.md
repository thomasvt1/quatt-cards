# Quatt Cards icon

The custom project icon combines a blue Q with airflow waves, reflecting heat pumps and room cooling. Generated with the built-in image-generation tool. This is a community-project mark, not the official Quatt company logo. Distributed under AGPL-3.0-or-later with the project.

icon-generated.png is the original generated raster used in the repository README and HACS repository detail page. It requires no runtime assets in the cards themselves. See [generation prompt](prompt.txt).

HACS currently uses a fixed dashboard-category icon for plugin repositories. Only integration repositories use brand images in the repository list. There is no supported hacs.json icon setting for dashboard plugins, so this asset does not replace that list icon.

Sources checked 9 October 2026: [repository list renderer](https://github.com/hacs/frontend/blob/main/src/dashboards/hacs-dashboard.ts), [category icons](https://github.com/hacs/frontend/blob/main/src/tools/type-icon.ts), [supported manifest fields](https://www.hacs.xyz/docs/publish/start/#hacsjson).
